# Quietboard

All code written must be bottlenecked by physical reality. The bottleneck is never allowed to be the implementation itself.

Keep this an independently installable experiment. Do not change the stable
InstinctaZero app, its data, or the PC gateway to support a UI experiment.
Use synthetic games and repertoires for tests; never commit pairing details,
private books or signing material. The USB-tethering phone is not a test device.
